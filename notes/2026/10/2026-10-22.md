## Remote sensing / geology / archaeology
- **GEM-15: Near-Global Surface and Terrain Elevation Models (15m)** (https://developers.google.com/earth-engine/datasets/catalog/projects_climate-and-sustainability_assets_gem-15_v1): An experimental Google Research elevation dataset added to the Earth Engine catalog on 13 October 2026 ([release notes](https://developers.google.com/earth-engine/docs/data-catalog/release-notes)), built from sub-meter optical stereo imagery (Pleiades Neo, WorldView, GeoEye, SPOT) through 2024 and aggregated to 15 m, with a `dsm` band, a deep-learning bare-earth `dtm` band, and `dsm_std` plus 5/50/95 percentile bands; CC-BY 4.0. Twice the resolution of cop-dem-glo-30 and with a separate DTM, so slope, aspect and flow over Kayaköy can be rerun and compared, and `dsm` minus `dtm` or `dsm_std` may help separate walls and terraces from terrain; the page reports regional offsets of about -4.8 m to +1.9 m against airborne lidar and weaker DTM accuracy in dense forest, and tile coverage for Turkey is not confirmed on the page (unverified). The page mentions a GCS STAC catalog, so access without Earth Engine may be possible (unverified). Recommendation: read.
- **arXiv:2610.25258, "Emergent Sparsity: How Many Effective Variables Survive Coarse-Graining in AlphaEarth Embeddings?"** (https://arxiv.org/abs/2610.25258): A paper on how many effective variables remain in AlphaEarth satellite embeddings when they are aggregated to coarser scales (from the physics.geo-ph recent listing, 21 October 2026, https://arxiv.org/list/physics.geo-ph/recent). Relevant if embeddings are considered as input features for the anomaly map instead of raw spectral indices; abstract, method and code not read (unverified). Recommendation: watch.

## Token Optimization System
- **Graphify-Labs/graphify** (https://github.com/Graphify-Labs/graphify): Turns a codebase plus docs, SQL schemas, configs and PDFs into a queryable knowledge graph, used as a `/graphify` skill in Claude Code with an optional MCP stdio server; code is parsed locally with tree-sitter, the README states "No telemetry, no usage tracking, no analytics", Apache-2.0 and MIT. Fits as a comparison point: graph-scoped subgraph queries instead of BM25 snippets; docs and PDFs are sent to the assistant's model or an API key unless Ollama is used, it writes a local query log by default (`~/.cache/graphify-queries.log`, can be disabled), and the 80% token saving claim belongs to the paid Graphify Cloud, not the open-source tool. Stars: about 132.6k on the repo page; listed on Trendshift daily (https://trendshift.io/). Recommendation: read.
- **arXiv:2610.21165, "From Long Context to Selective Memory: A Survey of Memory-Centric Compression for Large Language Models"** (https://arxiv.org/abs/2610.21165): A survey (submitted 15 October 2026) that frames context compression as memory management, modelling write, offload, recall, eviction, consolidation and forgetting as state transitions with a budgeted cost model. Useful vocabulary and taxonomy for the optimizer's retrieval vs eviction decisions; no code link. Recommendation: read.
- **Claude Code 2.1.303 to 2.1.308** (https://www.havoptic.com/releases/claude-code/2026/10): 2.1.306 (21 October) fixes a misleading message with large MCP tool setups; 2.1.307 (21 October) fixes MCP reconnects after sleep and keychain locks and adds a safety telemetry event for every tool call that is stopped or prompted; no compaction or token changes listed. Note the new telemetry event given the no-telemetry rule for your own tools. Summaries come from a third-party page (some entries truncated). Recommendation: watch.
