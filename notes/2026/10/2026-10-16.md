## Token Optimization System
- **Claude Code 2.1.296 / 2.1.299 / 2.1.300** (https://github.com/anthropics/claude-code/blob/main/CHANGELOG.md): 2.1.299 adds automatic compaction for idle sessions over 200K tokens before the cache expires (`CLAUDE_CODE_IDLE_COMPACT_MIN_TOKENS`) and `CLAUDE_CODE_DISABLE_FILE_MENTIONS`, which sends only the path instead of the content for `@` file mentions; 2.1.296 raises the MCP tool description and server instruction limit from 2,048 to 4,096 characters. Directly relevant to the size of your MCP server's tool descriptions and to context management. Release dates are not on the page. Recommendation: read.
- **PRIME** (https://arxiv.org/abs/2610.13296): Coarse-to-fine section retrieval for long documents using the heading hierarchy and deterministic metadata; per the abstract it matches structure-aware chunking in quality while cutting embedding compute by 45.8x and index vector count by 22.4x. The heading-based two-stage retrieval idea could be adapted to the embedding-free FTS5/BM25 side; it does not say whether it was tried with BM25, and there is no code link. Recommendation: read.
- **SAFE-QE** (https://arxiv.org/abs/2610.13810): A training-free method that filters LLM-generated query expansion terms, dropping those that appear consistently in random contexts but have no support in pseudo-relevant documents; nDCG@10 is on par with other methods, with 4.3 unsupported terms per query (Query2doc 27.8, HyDE 57.5). For sparse/lexical retrieval; it does not say it was tested with BM25, no code. Recommendation: watch.
