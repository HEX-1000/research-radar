## Token Optimization System
- **mksglu/context-mode** (https://github.com/mksglu/context-mode): An MCP server that runs tool calls in a sandboxed subprocess so only stdout enters context, and indexes content and session events in local SQLite FTS5 with BM25, Porter stemming and trigram matching, merged by Reciprocal Rank Fusion. Nearly the same design as your optimizer, useful for comparing ranking fusion and post-compaction session recovery; license is Elastic License 2.0, there is an optional hosted "Insight" dashboard, and default telemetry status is not stated on the page (unverified). Stars: 29,911 on GitHub trending (+904 today), about 30.4k on the repo page. Recommendation: read (source code only, do not install until telemetry is checked).
- **xerj-org/xerj** (https://github.com/xerj-org/xerj): A single-binary Rust search engine with an Elasticsearch-compatible API that indexes a folder with BM25 (plus optional kNN and hybrid), binds to 127.0.0.1 by default, and extracts PDF, DOCX, PPTX (one record per slide) and XLSX (one dataset per sheet); Apache-2.0. Fits the Office/PDF text extraction and BM25 side; optional reranker and proxy embeddings send text off the machine when enabled, and the README measures 2.7x fewer output tokens than grep against a 40x headline claim. Stars: 5,997 on GitHub trending (+715 today), about 7.5k on the repo page. Recommendation: watch.
- **arXiv:2610.21267, "TRACER: Trajectory-Aware Tool Retrieval for LLM Agents"** (https://arxiv.org/abs/2610.21267): Ranks likely next tools from past tool-call sequences and exposes only a small subset to the model, cutting input tokens by about 80% per the cs.IR listing summary. Relevant to how many MCP tool descriptions sit in context; code link unverified (abstract page did not load). Recommendation: read.
